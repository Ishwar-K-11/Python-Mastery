```text
=========================================================
         MOST IMPORTANT BUILT-IN EXCEPTION TYPES
=========================================================

    Exception
        → Base class for almost all built-in exceptions.

    ArithmeticError
        → Base class for arithmetic-related exceptions.

    ZeroDivisionError
        → Raised when division or modulo is performed by zero.

    OverflowError
        → Raised when the result of an arithmetic operation is too large.

    FloatingPointError
        → Raised for floating-point operation failures (rarely used).

    AssertionError
        → Raised when an assert statement fails.

    AttributeError
        → Raised when an object has no requested attribute.

    BufferError
        → Raised when a buffer-related operation fails.

    EOFError
        → Raised when input() reaches the end of a file without reading data.

    ImportError
        → Raised when an imported module cannot be found.

    ModuleNotFoundError
        → Raised when the specified module does not exist.

    IndexError
        → Raised when a sequence index is out of range.

    KeyError
        → Raised when a dictionary key is not found.

    LookupError
        → Base class for IndexError and KeyError.

    MemoryError
        → Raised when the system runs out of memory.

    NameError
        → Raised when a variable or name is not defined.

    UnboundLocalError
        → Raised when a local variable is referenced before assignment.

    NotImplementedError
        → Raised when a method is declared but not implemented.

    OSError
        → Base class for operating system-related errors.

    FileNotFoundError
        → Raised when a file or directory cannot be found.

    PermissionError
        → Raised when permission is denied for an operation.

    IsADirectoryError
        → Raised when a file operation is attempted on a directory.

    NotADirectoryError
        → Raised when a directory operation is attempted on a file.

    InterruptedError
        → Raised when a system call is interrupted.

    ProcessLookupError
        → Raised when a specified process does not exist.

    TimeoutError
        → Raised when an operation exceeds the allowed time.

    ReferenceError
        → Raised when a weak reference refers to a deleted object.

    RuntimeError
        → Raised for errors that do not fit another category.

    RecursionError
        → Raised when the maximum recursion depth is exceeded.

    StopIteration
        → Raised to signal the end of an iterator.

    StopAsyncIteration
        → Raised to stop an asynchronous iterator.

    SyntaxError
        → Raised when Python encounters invalid syntax.

    IndentationError
        → Raised when indentation is incorrect.

    TabError
        → Raised when tabs and spaces are mixed incorrectly.

    SystemError
        → Raised when the Python interpreter encounters an internal error.

    SystemExit
        → Raised by the sys.exit() function.

    KeyboardInterrupt
        → Raised when the user interrupts the program (Ctrl + C).

    TypeError
        → Raised when an operation is applied to an object of an inappropriate type.

    ValueError
        → Raised when a function receives the correct type but an invalid value.

    UnicodeError
        → Base class for Unicode-related errors.

    UnicodeEncodeError
        → Raised during Unicode encoding failure.

    UnicodeDecodeError
        → Raised during Unicode decoding failure.

    UnicodeTranslateError
        → Raised during Unicode translation failure.

    Warning
        → Base class for all warning categories.

    UserWarning
        → General warning generated by user code.

    DeprecationWarning
        → Warns that a feature is deprecated.

    PendingDeprecationWarning
        → Warns that a feature will be deprecated in the future.

    RuntimeWarning
        → Warning related to runtime behavior.

    SyntaxWarning
        → Warning for questionable syntax.

    FutureWarning
        → Warns about future incompatible changes.

    ImportWarning
        → Warning related to imports.

    UnicodeWarning
        → Warning related to Unicode usage.

    BytesWarning
        → Warning related to bytes and bytearray usage.

    ResourceWarning
        → Warning related to unclosed system resources.
    ```
