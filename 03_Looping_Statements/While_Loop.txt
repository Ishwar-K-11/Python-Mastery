================================================================================
                              WHILE LOOP IN PYTHON
================================================================================

Definition

    A while loop repeatedly executes a block of code as long as the given
    condition remains True. It is used when the number of iterations is
    unknown.

--------------------------------------------------------------------------------
1. Syntax
--------------------------------------------------------------------------------

    while condition:
        statements

--------------------------------------------------------------------------------
2. Basic Example
--------------------------------------------------------------------------------

Example

    i = 1

    while i <= 5:
        print(i)
        i += 1

Output

    1
    2
    3
    4
    5

--------------------------------------------------------------------------------
3. Infinite Loop
--------------------------------------------------------------------------------

Definition

    An infinite loop occurs when the condition never becomes False.

Example

    while True:
        print("Hello")

Note

    Always provide a condition or break statement to terminate the loop.

--------------------------------------------------------------------------------
4. Nested while Loop
--------------------------------------------------------------------------------

Definition

    A while loop inside another while loop.

Example

    i = 1

    while i <= 3:
        j = 1

        while j <= 2:
            print(i, j)
            j += 1

        i += 1

Output

    1 1
    1 2
    2 1
    2 2
    3 1
    3 2

--------------------------------------------------------------------------------
5. break Statement
--------------------------------------------------------------------------------

Definition

    Exits the loop immediately.

Example

    i = 1

    while i <= 5:
        if i == 4:
            break
        print(i)
        i += 1

Output

    1
    2
    3

--------------------------------------------------------------------------------
6. continue Statement
--------------------------------------------------------------------------------

Definition

    Skips the current iteration and continues with the next iteration.

Example

    i = 0

    while i < 5:
        i += 1

        if i == 3:
            continue

        print(i)

Output

    1
    2
    4
    5

--------------------------------------------------------------------------------
7. pass Statement
--------------------------------------------------------------------------------

Definition

    Placeholder statement that performs no action.

Example

    while False:
        pass

--------------------------------------------------------------------------------
8. else with while Loop
--------------------------------------------------------------------------------

Definition

    The else block executes after the while loop finishes normally.

Example

    i = 1

    while i <= 3:
        print(i)
        i += 1
    else:
        print("Loop Finished")

Output

    1
    2
    3
    Loop Finished

--------------------------------------------------------------------------------
9. Flow of Execution
--------------------------------------------------------------------------------

                 Start
                    |
             Initialize Variable
                    |
             Check Condition
              /            \
          True              False
            |                  |
      Execute Statements      Exit
            |
      Update Variable
            |
            +------------------+

--------------------------------------------------------------------------------
10. Important Points
--------------------------------------------------------------------------------

• Used when the number of iterations is unknown.
• Executes until the condition becomes False.
• The loop variable must be updated manually.
• Supports break, continue, pass, and else.
• Infinite loops occur if the condition never changes.

--------------------------------------------------------------------------------
11. Best Practices
--------------------------------------------------------------------------------

✓ Always update the loop variable.
✓ Ensure the condition eventually becomes False.
✓ Avoid unnecessary infinite loops.
✓ Keep conditions simple and readable.
✓ Use while only when a for loop is not suitable.
