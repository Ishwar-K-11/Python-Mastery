=========================================
REFERENCE COPY
=========================================

    Definition:
        A reference copy does not create a new object. Both variables point to the same object in memory.

    Syntax:
        new_variable = original_variable

    Example:
        list1 = [10, 20, 30]
        list2 = list1

        list2.append(40)

        print(list1)   # [10, 20, 30, 40]
        print(list2)   # [10, 20, 30, 40]

    Note:
        - No new object is created.
        - Changes made using one variable affect the other.
        - Fastest type of copying.


=========================================
SHALLOW COPY
=========================================

    Definition:
        A shallow copy creates a new outer object, but nested objects are shared between the original and the copy.

    Syntax:
        import copy
        new_variable = copy.copy(original_variable)

                            OR

        new_variable = original_variable.copy()   # For lists, dictionaries, sets

    Example:
        import copy

        list1 = [[1, 2], [3, 4]]
        list2 = copy.copy(list1)

        list2[0].append(100)

        print(list1)   # [[1, 2, 100], [3, 4]]
        print(list2)   # [[1, 2, 100], [3, 4]]

    Note:
        - Creates a new outer object.
        - Nested objects are shared.
        - Changes to nested objects affect both copies.


=========================================
DEEP COPY
=========================================

    Definition:
        A deep copy creates a completely independent copy of the original object, including all nested objects.

    Syntax:
        import copy
        new_variable = copy.deepcopy(original_variable)

    Example:
        import copy

        list1 = [[1, 2], [3, 4]]
        list2 = copy.deepcopy(list1)

        list2[0].append(100)

        print(list1)   # [[1, 2], [3, 4]]
        print(list2)   # [[1, 2, 100], [3, 4]]

    Note:
        - Creates a completely new object.
        - Copies all nested objects.
        - Changes in one object do not affect the other.
        - Used for nested lists, dictionaries, and complex objects.
